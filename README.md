Respells [IPA (International Phonetic Alphabet)](https://en.wikipedia.org/wiki/International_Phonetic_Alphabet) into a single English-friendly canonical pronunciation spelling.

The scheme was informed by the [Wikipedia pronunciation respelling key](https://en.wikipedia.org/wiki/Help:Pronunciation_respelling_key) and [Dictionary.com's IPA key](https://www.dictionary.com/e/key-to-ipa-pronunciations/), but it is project-owned and intentionally diverges where its own rules require.

See the [canonical respelling scheme](docs/canonical-respelling-scheme.md) for the rules, supported distinctions, and representative examples.
